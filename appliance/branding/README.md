# Naming and trademark (user research, 2026-09-29)

- Product name: **CyberHygiene Project Lab Installer (EL9 / Rocky Linux 9 compatible)**
- ISO file name: `cyberhygiene-lab-installer-el9.iso` (a version suffix is allowed)
- Never: `Rocky-9-CyberHygiene.iso`, "Rocky Linux CyberHygiene Edition", "Rocky Linux by The CyberHygiene Project",
  or any name implying official origin.
- `NOTICE.txt` goes at the ISO root and in the release folder; `boot-banner.txt` is the boot-menu / installer banner;
  `file-header.txt` heads every script and kickstart the installer ships.
- Rocky's own packages ship **unmodified** under their own licenses (BSD-3 notices retained).
