CyberHygiene Project Lab Installer
=================================

This image is an internal test artifact of The CyberHygiene Project.
It is not published, sponsored, endorsed, or supported by the Rocky
Enterprise Software Foundation (RESF).

Base system
-----------
This installer is built from Rocky Linux 9 packages and official
Rocky Linux 9 installation media, with project-specific kickstart
data, packages, and configuration added by The CyberHygiene Project.

Compatibility statement (factual only)
--------------------------------------
CyberHygiene Project Lab Installer for use with Rocky Linux 9.
Compatible with Rocky Linux 9.
