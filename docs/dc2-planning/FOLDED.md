# About this folder

This folder is the former `cyberhygiene-dc2` repository (dc2 / cyberappliance.tech planning, August–September 2026),
folded into this repository on 2026-10-30 with its commit history. The files are as they were, except:

- **`anaconda-ks.cfg` is not here.** It was byte-identical to `lab/kickstart/dc2-reference/anaconda-ks.cfg`; use that
  copy.
- **`dc2-cui-tailoring.xml` here is the original** dc2 tailoring file. The copy in `lab/kickstart/dc2-reference/`
  differs; it is the lab's working copy. Both are kept.

`docs/adr/0001-replace-freeipa-with-kanidm.md` is the ADR 0001 that `lab/adr0001-q1-packaging.md` and
`lab/adr0001-q2-fips.md` answer.
