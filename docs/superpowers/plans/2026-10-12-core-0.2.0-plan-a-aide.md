# Core 0.2.0 Plan A: AIDE file integrity (package, commands, measurement, proofs) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed `chp-integrity` package plus new `chp-site` commands that build an AIDE baseline, check it daily, alert through the CHP monitor, accept changes only with a recorded ISSO/delegate approval, and pin each baseline's hash to the site stick — proved on lab hosts by catching planted changes.

**Architecture:** Python logic in `chp_site` (stdlib only, runs on EL9 Python 3.9): a new `aide.py` module (records, pin, report parsing, rpm grouping, accept) wired into `cli.py`; the site-stick mount logic is pulled out of `export-client` into a reusable context manager. A new noarch RPM `chp-integrity` ships `/etc/aide.conf` (Rocky stock + the SSG's own remediation + CHP additions), two bash scripts (daily check wrapper, baseline builder), systemd units, and three monitor checks. Proofs run on the iso5 golden hosts (revert to golden afterwards).

**Tech Stack:** Python 3.9 stdlib, bash, systemd, AIDE 0.19.2 (Rocky 9.8 DVD), rpmbuild on aero, OpenSCAP + SSG, pytest on the Mac.

**Spec:** `docs/superpowers/specs/2026-10-12-core-0.2.0-aide-design.md` (APPROVED 2026-10-12). Read it with this plan.

## Review Focus

1. **`aide-accept` when the live database is not the recorded baseline** (someone replaced it): a person expects a refusal that says "investigate first", not a silent re-baseline. → Task 5 test `test_accept_refuses_a_replaced_database_unless_investigated`.
2. **`aide-accept` when the fresh AIDE check itself errors** (exit ≥ 14): expect refusal with nothing changed, not a new baseline built over a broken config. → Task 5 test `test_accept_refuses_when_the_fresh_check_fails`.
3. **Two pins of the same host in the same second** (history file name collision): expect both older records kept, nothing overwritten. → Task 3 test `test_pin_history_never_overwrites_even_in_the_same_second`.
4. **A malformed or half-written `last-result`** (wrapper killed mid-write, disk full): expect an ALERT, not a crash or a silent OK. → Task 8 test `test_result_unreadable_is_an_alert`.
5. **On the server, `client.done` appears before `server.done`** (self-client steps): the baseline must wait for `server.done`. → Task 7 test `test_baseline_on_the_server_waits_for_server_done`.

```python
@contextmanager
def site_stick(stick=None, label="/dev/disk/by-label/OEMDRV", run=subprocess.run):
    """Yield the site stick's directory. With `stick` (tests, lab) that directory. Otherwise authorize ONLY the pinned
    stick through USBGuard (temporarily), mount it, yield, then sync, unmount and block it again, whatever happened."""
    if stick:
        yield Path(stick)
        return
    dev = Path(label)
    usb = allow_stick(dev)
    try:
        mnt = tempfile.mkdtemp(prefix="chp-stick-", dir="/run" if os.path.isdir("/run") else None)
        try:
            if run(["mount", str(dev), mnt]).returncode != 0:
                raise SiteError("could not mount the site stick")
            try:
                yield Path(mnt)
            finally:
                run(["sync"])
                if run(["umount", mnt]).returncode != 0:
                    raise SiteError(f"could not unmount the site stick ({mnt}); do not unplug it yet")
        finally:
            try:
                os.rmdir(mnt)
            except OSError:
                pass
    finally:
        block_stick(usb)
```

```python
"""File integrity (core 0.2.0, spec 2026-10-12): AIDE baseline records, the site-stick pin, report parsing, and the
approved, audited baseline change (aide-accept). The daily check itself is a shell wrapper (chp-integrity RPM)."""
import hashlib
import os
import re
import time
from pathlib import Path

from .sitefile import SiteError

DB = Path("/var/lib/aide/aide.db.gz")
NEW_DB = Path("/var/lib/aide/aide.db.new.gz")
STATE = Path("/var/lib/chp/aide")
LOGDIR = Path("/var/log/aide")
_BUILT_BY = re.compile(r"first-boot|package-install|accepted:[^\x00-\x1f=]{1,64}")


def stamp(t=None):
    return time.strftime("%Y%m%dT%H%M%SZ", time.gmtime(t))


def sha512_file(path):
    h = hashlib.sha512()
    with open(path, "rb") as f:
        for block in iter(lambda: f.read(1 << 20), b""):
            h.update(block)
    return h.hexdigest()


def read_record(path):
    """KEY=value lines -> dict; a missing file is {}."""
    try:
        text = Path(path).read_text()
    except FileNotFoundError:
        return {}
    return dict(line.split("=", 1) for line in text.splitlines() if "=" in line)


def write_record(path, rec, mode=0o644):
    """Atomic: write a temp file, fsync, chmod, rename over the old one (a reader never sees half a record)."""
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_name(path.name + ".tmp")
    fd = os.open(tmp, os.O_WRONLY | os.O_CREAT | os.O_TRUNC, mode)
    with os.fdopen(fd, "w") as f:
        f.write("".join(f"{k}={v}\n" for k, v in rec.items()))
        f.flush()
        os.fsync(f.fileno())
    os.chmod(tmp, mode)
    os.replace(tmp, path)


def baseline_record(db, built_by, now):
    if not _BUILT_BY.fullmatch(built_by):
        raise ValueError(f"BUILT_BY {built_by!r}")
    return {"DB_SHA512": sha512_file(db), "BUILT_AT": stamp(now), "BUILT_EPOCH": str(int(now)), "BUILT_BY": built_by}


def write_pin(stick, host, base, now):
    """aide/<host>.txt on the site stick; an existing record is first renamed aide/<host>.<its PINNED_AT>[-n].txt
    (history kept, nothing overwritten). Written, fsync'd and read back."""
    if not base.get("DB_SHA512"):
        raise SiteError("no AIDE baseline on this host yet (nothing to pin)")
    d = Path(stick) / "aide"
    d.mkdir(exist_ok=True)
    cur = d / f"{host}.txt"
    if cur.exists():
        old = read_record(cur).get("PINNED_AT", "unknown")
        n = 0
        while (d / f"{host}.{old}{'' if n == 0 else f'-{n}'}.txt").exists():
            n += 1
        os.rename(cur, d / f"{host}.{old}{'' if n == 0 else f'-{n}'}.txt")
    rec = {"HOST": host, "DB_SHA512": base["DB_SHA512"], "BUILT_AT": base.get("BUILT_AT", ""),
           "BUILT_BY": base.get("BUILT_BY", ""), "PINNED_AT": stamp(now)}
    text = "".join(f"{k}={v}\n" for k, v in rec.items())
    with open(cur, "w") as f:
        f.write(text)
        f.flush()
        os.fsync(f.fileno())
    if cur.read_text() != text:
        raise SiteError(f"the pin record on the stick reads back differently ({cur}); do not trust it")
    return cur


def verify_pin(stick, host, db_sha):
    rec = read_record(Path(stick) / "aide" / f"{host}.txt")
    if not rec.get("DB_SHA512"):
        raise SiteError(f"the site stick has no AIDE pin for {host} (aide/{host}.txt)")
    return rec["DB_SHA512"] == db_sha, rec["DB_SHA512"]


_SECTION = re.compile(r"^(Added|Removed|Changed) entries:\s*$")
_ENTRY = re.compile(r"^\S[^:]*:\s(/.*)$")


def parse_report(text):
    """Paths from AIDE's plain grouped report (report_grouped=yes): the Added/Removed/Changed sections only."""
    out, cur = {"added": [], "removed": [], "changed": []}, None
    for line in text.splitlines():
        s = line.rstrip()
        if s.startswith(("Detailed information about changes", "The attributes of the")):
            break
        m = _SECTION.match(s)
        if m:
            cur = m.group(1).lower()
            continue
        e = _ENTRY.match(s) if cur else None
        if e:
            out[cur].append(e.group(1))
    return out
```

```python
PINNED_SIGNERS = {"521276f43c908f8e": "CyberHygiene", "8a3872bf3228467c": "EPEL 9", "702d426d350d275d": "Rocky 9"}
_SIGQF = "%{INSTALLTIME} %|DSAHEADER?{%{DSAHEADER:pgpsig}}:{%|RSAHEADER?{%{RSAHEADER:pgpsig}}:{(none)}|}|\n"


class Rpm:
    """Read-only questions to the rpm database (cached per package)."""
    def __init__(self, run=subprocess.run):
        self.run, self._info, self._mod = run, {}, {}

    def owner(self, path):
        r = self.run(["rpm", "-qf", "--qf", "%{NAME}\n", path], capture_output=True, text=True)
        return r.stdout.splitlines()[0].strip() if r.returncode == 0 and r.stdout.strip() else None

    def info(self, name):
        if name not in self._info:
            r = self.run(["rpm", "-q", "--qf", _SIGQF, name], capture_output=True, text=True)
            line = r.stdout.splitlines()[0] if r.returncode == 0 and r.stdout else ""
            t, _, sig = line.partition(" ")
            m = re.search(r"Key ID ([0-9a-f]{16})", sig)
            self._info[name] = (int(t) if t.isdigit() else 0, m.group(1) if m else None)
        return self._info[name]

    def modified(self, name):
        if name not in self._mod:
            r = self.run(["rpm", "-V", name], capture_output=True, text=True)
            self._mod[name] = {line.split()[-1] for line in r.stdout.splitlines() if line.strip()}
        return self._mod[name]


def group(changes, rpm, built_epoch):
    """Split AIDE's paths into (explained, unexplained). Explained = added/changed path owned by a package installed or
    updated after the baseline, that rpm -V reports unmodified, signed by a pinned key. A reading aid only: nothing is
    accepted automatically. A removed path is always unexplained (no owner left to ask)."""
    explained, unexplained = {}, []
    for kind in ("added", "removed", "changed"):
        for p in changes.get(kind, []):
            name = rpm.owner(p) if kind != "removed" else None
            if name:
                t, key = rpm.info(name)
                if t > built_epoch and key in PINNED_SIGNERS and p not in rpm.modified(name):
                    explained.setdefault(name, []).append(p)
                    continue
            unexplained.append((kind, p))
    return explained, unexplained
```

```python
def run_aide(*args):
    import subprocess as sp
    r = sp.run(["aide", *args], capture_output=True, text=True)
    return r.returncode, r.stdout + r.stderr


def _summary(changes, explained, unexplained):
    lines = [f"AIDE changes since the baseline: {len(changes['added'])} added, {len(changes['removed'])} removed, "
             f"{len(changes['changed'])} changed", ""]
    n_exp = sum(len(v) for v in explained.values())
    lines.append(f"Explained by signed package updates: {n_exp} paths in {len(explained)} packages")
    for pkg in sorted(explained):
        lines.append(f"  {pkg}: {len(explained[pkg])} paths")
    lines += ["", f"NOT explained: {len(unexplained)} paths (review every one)"]
    lines += [f"  {kind:8} {p}" for kind, p in unexplained]
    return "\n".join(lines)


def accept(site, approver, reason, *, host, aide, rpm, confirm, say=print, rec=audit.record,
           investigated_mismatch=False, db=DB, new_db=NEW_DB, state=STATE, logdir=LOGDIR, now=time.time):
    """spec §6.1: approve (ISSO or BASELINE_DELEGATES), fresh check, grouped summary, confirm, audit, new baseline.
    Returns the new baseline record, or None when there is nothing to accept."""
    from .ops import approved_by, checked_reason
    approver = approved_by(site, approver, "BASELINE_DELEGATES")
    reason = checked_reason(reason, "why these changes are legitimate")
    state, logdir, db, new_db = Path(state), Path(logdir), Path(db), Path(new_db)
    base = read_record(state / "baseline")
    if not base.get("DB_SHA512") or not db.exists():
        raise SiteError("no AIDE baseline on this host (nothing to accept against): see the 60-aide-result alert")
    mismatch = sha512_file(db) != base["DB_SHA512"]
    if mismatch and not investigated_mismatch:
        raise SiteError("the AIDE database is NOT the recorded baseline (replaced outside aide-accept?): investigate "
                        "first; only then re-run with --database-mismatch-investigated")
    rc, text = aide("--check")
    if rc < 0 or rc >= 14:
        raise SiteError(f"the fresh AIDE check failed (exit {rc}); nothing was changed")
    if rc == 0 and not mismatch:
        say("AIDE: no changes since the baseline; nothing to accept")
        return None
    t = now()
    logdir.mkdir(mode=0o700, parents=True, exist_ok=True)
    rep = logdir / f"accept-{stamp(t)}.log"
    rep.write_text(text)
    rep.chmod(0o600)
    changes = parse_report(text)
    explained, unexplained = group(changes, rpm, int(base.get("BUILT_EPOCH", "0") or 0))
    say(_summary(changes, explained, unexplained))
    if not confirm():
        raise SiteError("not accepted; nothing was changed")
    fields = {"host": host, "approver": approver, "reason": reason, "operator": audit.operator(),
              "explained": sum(len(v) for v in explained.values()), "unexplained": len(unexplained),
              "db_mismatch": "investigated" if mismatch else "no", "old_sha512": base["DB_SHA512"], "report": str(rep)}
    rec("aide-accept", fields)
    if new_db.exists():
        new_db.unlink()
    rc2, _out = aide("--init")
    if rc2 != 0 or not new_db.exists():
        raise SiteError(f"aide --init failed (exit {rc2}); the old baseline is unchanged")
    os.replace(new_db, db)
    os.chmod(db, 0o600)
    t2 = now()
    nb = baseline_record(db, f"accepted:{approver}", t2)
    write_record(state / "baseline", nb, 0o600)
    acc = logdir / "accepted"
    acc.mkdir(mode=0o700, exist_ok=True)
    shutil.copy2(rep, acc / rep.name)
    write_record(state / "last-result", {"TIME": stamp(t2), "EPOCH": str(int(t2)), "EXIT": "0", "ADDED": "0",
                                         "REMOVED": "0", "CHANGED": "0", "DB_MATCH": "yes",
                                         "REPORT": str(acc / rep.name)}, 0o644)
    rec("aide-accept.done", {**fields, "new_sha512": nb["DB_SHA512"]}, after=True)
    say(f"accepted by {approver}: new baseline {nb['DB_SHA512'][:16]}… (recorded in the audit log)")
    return nb
```

```bash
#!/bin/bash
# CyberHygiene Project Lab Installer — based on Rocky Linux 9.
# Not an official Rocky Linux product.
# Rocky Linux is a trademark of the Rocky Enterprise Software Foundation.
# aide-check (chp-aide-check.service, daily; spec 2026-10-12 §5.2): compare the database with the recorded baseline
# hash, run `aide --check`, record the exit code and counts in last-result (atomically) and one journal line.
# AIDE exit: 0 clean; 1-7 = added(1)/removed(2)/changed(4) bits; >=14 AIDE error. Never rebuilds or replaces a database.
set -uo pipefail
S=${CHP_AIDE_STATE:-/var/lib/chp/aide}; DB=${CHP_AIDE_DB:-/var/lib/aide/aide.db.gz}
L=${CHP_AIDE_LOG:-/var/log/aide}; AIDE=${CHP_AIDE_BIN:-/usr/sbin/aide}
sha() { if command -v sha512sum >/dev/null 2>&1; then sha512sum "$1"; else shasum -a 512 "$1"; fi | cut -d' ' -f1; }
mkdir -p "$S" "$L" && chmod 0755 "$S" && chmod 0700 "$L" || exit 1
now=$(date -u +%s); t=$(date -u +%Y%m%dT%H%M%SZ); rep="$L/check-$t.log"
match=no-baseline
if [ -f "$DB" ] && [ -f "$S/baseline" ]; then
  want=$(sed -n 's/^DB_SHA512=//p' "$S/baseline" | head -1)
  if [ -n "$want" ] && [ "$want" = "$(sha "$DB")" ]; then match=yes; else match=no; fi
fi
"$AIDE" --check > "$rep" 2>&1; rc=$?
chmod 0600 "$rep"
count() { awk -v k="$1" '$0 ~ "^[ \t]*" k " entries:[ \t]+[0-9]+[ \t]*$" {print $NF; exit}' "$rep"; }
a=$(count Added); r=$(count Removed); c=$(count Changed)
tmp="$S/last-result.tmp"
printf 'TIME=%s\nEPOCH=%s\nEXIT=%s\nADDED=%s\nREMOVED=%s\nCHANGED=%s\nDB_MATCH=%s\nREPORT=%s\n' \
  "$t" "$now" "$rc" "${a:-0}" "${r:-0}" "${c:-0}" "$match" "$rep" > "$tmp" && chmod 0644 "$tmp" && mv -f "$tmp" "$S/last-result" || exit 1
logger -p authpriv.notice -t chp-aide "check: exit $rc added=${a:-0} removed=${r:-0} changed=${c:-0} db_match=$match"
exit 0
```

```bash
#!/bin/bash
# CyberHygiene Project Lab Installer — based on Rocky Linux 9.
# Not an official Rocky Linux product.
# Rocky Linux is a trademark of the Rocky Enterprise Software Foundation.
# aide-baseline (chp-aide-baseline.service; spec 2026-10-12 §5.1): build the FIRST AIDE baseline once this host's role
# first boot has finished: server.done on the server (its client.done appears earlier, during the self-client steps),
# client.done on a client. Never overwrites an existing database. Exit 1 = not ready yet or failed (the unit retries).
set -uo pipefail
S=${CHP_AIDE_STATE:-/var/lib/chp/aide}; DB=${CHP_AIDE_DB:-/var/lib/aide/aide.db.gz}
NEW=${CHP_AIDE_NEWDB:-/var/lib/aide/aide.db.new.gz}; L=${CHP_AIDE_LOG:-/var/log/aide}
AIDE=${CHP_AIDE_BIN:-/usr/sbin/aide}; FB=${CHP_FIRSTBOOT_DIR:-/var/lib/chp/firstboot}
sha() { if command -v sha512sum >/dev/null 2>&1; then sha512sum "$1"; else shasum -a 512 "$1"; fi | cut -d' ' -f1; }
role=${CHP_ROLE:-$(rpm -q --quiet chp-identity-server && echo server || echo client)}
if [ -f "$DB" ]; then logger -t chp-aide "baseline: a database already exists; not rebuilt"; exit 0; fi
for _ in $(seq "${CHP_AIDE_WAIT:-60}"); do [ -e "$FB/$role.done" ] && break; sleep "${CHP_AIDE_POLL:-10}"; done
if [ ! -e "$FB/$role.done" ]; then
  logger -p authpriv.warning -t chp-aide "baseline: $role first boot not finished yet; will retry"; exit 1; fi
by=first-boot; [ -e "$S/installed-on-existing-host" ] && by=package-install
mkdir -p "$S" "$L" && chmod 0755 "$S" && chmod 0700 "$L" || exit 1
t=$(date -u +%Y%m%dT%H%M%SZ); e=$(date -u +%s)
rm -f "$NEW"
if ! "$AIDE" --init > "$L/init-$t.log" 2>&1 || [ ! -f "$NEW" ]; then
  logger -p authpriv.warning -t chp-aide "baseline: aide --init failed (see $L/init-$t.log)"; exit 1; fi
mv -f "$NEW" "$DB" && chmod 0600 "$DB" || exit 1
sum=$(sha "$DB")
printf 'DB_SHA512=%s\nBUILT_AT=%s\nBUILT_EPOCH=%s\nBUILT_BY=%s\n' "$sum" "$t" "$e" "$by" > "$S/baseline.tmp" \
  && chmod 0600 "$S/baseline.tmp" && mv -f "$S/baseline.tmp" "$S/baseline" || exit 1
logger -p authpriv.notice -t chp-aide "baseline built ($by) sha512=${sum:0:16}"
```

```bash
#!/usr/bin/env bash
# CyberHygiene Project Lab Installer — based on Rocky Linux 9.
# Not an official Rocky Linux product.
# Rocky Linux is a trademark of the Rocky Enterprise Software Foundation.
# prove-aide.sh STAGE (RUNS ON THE MAC): core 0.2.0 Plan A proofs on the iso5 golden hosts (srv1 = iso5-srv,
# client2 = iso5-cli2; chpadmin with the LAB ADAPTER's sudo). Spec §9: AIDE must CATCH planted changes.
#   upgrade   revert to golden; unpack repo 0.7.0; dnf upgrade chp-site + install chp-integrity; baseline package-install
#   pin       62 alerts before; aide-pin with the iso5 stick attached; 62 quiet; stick has aide/<host>.txt
#   catch     plant 3 changes on srv1; run the check; 60 alerts; ALERT_HOOK received it
#   accept    unlisted name refused; delegate accepts (BASELINE_DELEGATES added to /etc/chp/site.conf); audit; quiet
#   verify    aide-verify-pin MATCH; replace the database by hand -> DB_MATCH=no alert and MISMATCH
#   grouping  dnf reinstall chp-site, check, accept summary lists it under "explained"
#   stale     stop the timer -> alert; an old last-result -> alert
#   selinux   0 AVC since the upgrade; fapolicyd denials 0
#   revert    both hosts back to golden
set -uo pipefail
here="$(cd "$(dirname "$0")" && pwd)"; top="$(cd "$here/../.." && pwd)"; F="$top/lab/iso5/ssh_config"
STICK=/data/libvirt/images/iso5-stick.img; REPO=0.7.0; fails=0
pass() { echo "PASS $1"; }
fail() { echo "FAIL $1: ${2:-}"; fails=1; }
check() { if [[ $2 == "$3" ]]; then pass "$1"; else fail "$1" "got '$2', want '$3'"; fi; }
A() { ssh -n -o BatchMode=yes aero "$@" 2>/dev/null; }
H() { local h=$1; shift; ssh -F "$F" -n -o ConnectTimeout=10 "$h" "$@" 2>/dev/null; }
vm() { [[ $1 == srv1 ]] && echo iso5-srv || echo iso5-cli2; }
mon() { H "$1" "sudo bash -c 'for c in /usr/lib/chp/monitor.d/6*-aide-*.sh; do \$c; done'"; }
runcheck() { H "$1" 'sudo systemctl start chp-aide-check.service; sudo cat /var/lib/chp/aide/last-result'; }
attach() { A "sudo virsh attach-disk $(vm "$1") $STICK sdz --targetbus usb --type disk --live >/dev/null"; sleep 5; }
detach() { A "sudo virsh detach-disk $(vm "$1") sdz --live >/dev/null"; sleep 3; }

case ${1:-} in
  upgrade)
    "$top/lab/iso5/reset.sh" >/dev/null || { fail "reset to golden"; exit 1; }
    for h in srv1 client2; do
      H $h 'sudo rm -rf /var/lib/chp/repo/*'
      A "tar -C /data/lab-inputs/chp/$REPO -cf - ." | ssh -F "$F" "$h" 'sudo tar -x -C /var/lib/chp/repo -f -'     # the signed repo, as a site would unpack the tarball
      out=$(H $h "sudo dnf -y -q --enablerepo=chp upgrade chp-site && sudo dnf -y -q --enablerepo=chp install chp-integrity && echo INSTALLED")
      [[ $out == *INSTALLED* ]] && pass "$h: chp-site 0.7.0 + chp-integrity from the signed repo" || fail "$h install" "$out"
      check "$h: aide.conf is ours" "$(H $h 'sudo cmp -s /etc/aide.conf /usr/share/chp-integrity/aide.conf && echo same')" "same"
      s=""; for _ in $(seq 60); do s=$(H $h 'sudo sed -n s/^BUILT_BY=//p /var/lib/chp/aide/baseline 2>/dev/null'); [[ -n $s ]] && break; sleep 15; done
      check "$h: baseline built at package install" "$s" "package-install"
      check "$h: baseline built with our aide.conf (conf older than init log)" "$(H $h 'sudo bash -c "[ /etc/aide.conf -ot \$(ls -t /var/log/aide/init-*.log | head -1) ] && echo yes"')" "yes"
      check "$h: daily timer active" "$(H $h 'systemctl is-active chp-aide-check.timer')" "active"
      check "$h: database 0600" "$(H $h 'sudo stat -c %a /var/lib/aide/aide.db.gz')" "600"
      H $h "sudo sed -i 's#^ALERT_HOOK=.*#ALERT_HOOK=/usr/local/sbin/chp-test-hook#' /etc/chp/site.conf"     # replace: a 2nd ALERT_HOOK line is a parse error
      scp -q -F "$F" "$here/hook.sh" $h:/tmp/hook.sh && H $h 'sudo install -m 0755 /tmp/hook.sh /usr/local/sbin/chp-test-hook'
    done ;;
  pin)
    for h in srv1 client2; do
      [[ $(mon $h) == *"ALERT AIDE baseline not pinned"* ]] && pass "$h: 62 alerts before the pin" || fail "$h 62 before"
      attach $h; out=$(H $h 'sudo chp-site aide-pin'); detach $h
      [[ $out == pinned:* ]] && pass "$h: aide-pin ($out)" || fail "$h aide-pin" "$out"
      [[ $(mon $h) != *"not pinned"* ]] && pass "$h: 62 quiet after the pin" || fail "$h 62 after"
      check "$h: record on the stick" "$(A "sudo bash /tmp/iso2/stick.sh has $STICK aide/$(vm $h).txt && echo yes")" "yes"
    done ;;
  catch)
    H srv1 'sudo cp /usr/bin/true /usr/bin/chp-planted && echo "# planted" | sudo tee -a /etc/kanidm/config >/dev/null && echo "# planted" | sudo tee /etc/ssh/sshd_config.d/50-planted.conf >/dev/null'
    r=$(runcheck srv1)
    grep -qx 'EXIT=[1-7]' <<<"$r" && pass "srv1: check reports changes ($(grep -o 'ADDED=[0-9]*\|CHANGED=[0-9]*' <<<"$r" | tr '\n' ' '))" || fail "srv1 check" "$r"
    rep=$(H srv1 'sudo bash -c "cat \$(sed -n s/^REPORT=//p /var/lib/chp/aide/last-result)"')
    for p in /usr/bin/chp-planted /etc/kanidm/config /etc/ssh/sshd_config.d/50-planted.conf; do
      [[ $rep == *"$p"* ]] && pass "srv1: report names $p" || fail "srv1 report $p"; done

    H srv1 'echo "BASELINE_DELEGATES=Deputy ISSO" | sudo tee -a /etc/chp/site.conf >/dev/null'
    attach srv1
    out=$(H srv1 'sudo chp-site aide-accept --approver "Deputy ISSO" --reason "lab proof: planted test changes" --yes 2>&1'); detach srv1
    [[ $out == *"NOT explained"* && $out == *"/usr/bin/chp-planted"* && $out == *"accepted by Deputy ISSO"* && $out == *"pinned: aide/"* ]] \
      && pass "delegate accepted; summary listed the planted files; pinned" || fail "accept" "$out"
    [[ $(H srv1 'sudo sha512sum /var/lib/aide/aide.db.gz') != "$sha0" ]] && pass "new database installed" || fail "db unchanged"
    au=$(H srv1 'sudo ausearch -m USER -ts recent --input-logs </dev/null 2>/dev/null | grep -c "chp-site aide-accept"')
    [[ $au -ge 2 ]] && pass "audit: before + after records ($au)" || fail "audit" "$au"
    [[ $(mon srv1) == *"OK AIDE: no changes"* && $(mon srv1) != *ALERT* ]] && pass "monitor quiet after accept" || fail "after accept" "$(mon srv1)" ;;
  verify)
    attach srv1; out=$(H srv1 'sudo chp-site aide-verify-pin; echo rc=$?'); detach srv1
    [[ $out == MATCH* && $out == *rc=0* ]] && pass "verify-pin MATCH" || fail "verify MATCH" "$out"
    H srv1 'sudo cp /var/lib/aide/aide.db.gz /root/db.keep && echo x | sudo tee -a /var/lib/aide/aide.db.gz >/dev/null'
    r=$(runcheck srv1); [[ $r == *DB_MATCH=no* ]] && pass "replaced database: DB_MATCH=no" || fail "db match" "$r"
    [[ $(mon srv1) == *"does not match the recorded baseline"* ]] && pass "60 alerts on the replaced database" || fail "60 mismatch"
    attach srv1; out=$(H srv1 'sudo chp-site aide-verify-pin; echo rc=$?'); detach srv1
    [[ $out == MISMATCH* && $out == *rc=1* ]] && pass "verify-pin MISMATCH" || fail "verify MISMATCH" "$out"
    out=$(H srv1 'sudo chp-site aide-accept --approver "D. Shannon" --reason "must be refused: replaced db" --yes 2>&1')
    [[ $out == *"investigate"* ]] && pass "accept refused on a replaced database" || fail "accept mismatch" "$out"
    H srv1 'sudo cp /root/db.keep /var/lib/aide/aide.db.gz && sudo rm /root/db.keep'; runcheck srv1 >/dev/null ;;
  grouping)
    H srv1 'sudo dnf -y -q --enablerepo=chp reinstall chp-site'
    out=$(ssh -F "$F" srv1 'sudo chp-site aide-accept --approver "D. Shannon" --reason "lab proof: grouping after reinstall" 2>&1' <<<"NO")     # no -n: the prompt reads NO
    [[ $out == *"Explained by signed package updates"* && $out == *"chp-site:"* ]] && pass "reinstalled chp-site listed as explained" || fail "grouping" "$out"
    [[ $out == *"not accepted"* ]] && pass "declined: nothing changed" || fail "decline" "$out" ;;
  stale)
    H client2 'sudo systemctl stop chp-aide-check.timer'
    [[ $(mon client2) == *"timer is not active"* ]] && pass "timer stopped -> alert" || fail "timer alert"
    H client2 'sudo systemctl start chp-aide-check.timer && sudo systemctl start chp-aide-check.service && sudo sed -i "s/^EPOCH=.*/EPOCH=1000/" /var/lib/chp/aide/last-result'

    done ;;
  revert)
    A "sudo virsh snapshot-revert iso5-srv golden --running && sudo virsh snapshot-revert iso5-cli2 golden --running" && pass "reverted to golden" || fail "revert" ;;
```
